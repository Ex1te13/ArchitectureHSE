# Marketplace

Домашние задания по курсу архитектуры: маркетплейс. Каждое задание лежит в своей папке со своим README.

| Папка | Задание |
|---|---|
| [MarketplaceArchitecture](MarketplaceArchitecture/) | Архитектура маркетплейса: C4-диаграмма (уровень Container), домены и сервисы |
| [MarketplaceOpenAPI](MarketplaceOpenAPI/) | Marketplace API на Go: OpenAPI-контракт, CRUD товаров, PostgreSQL + Flyway, валидация, JSON-логи |

Запуск второго задания:

```bash
cd MarketplaceOpenAPI
docker compose up --build
```
